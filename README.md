# Radical.Avalonia

![Radical logo](assets/icon.png)

Radical framework is designed to help developing composite [Avalonia](https://avaloniaui.net/) applications based on the Model-View-ViewModel presentation pattern. Radical.Avalonia is the Avalonia counterpart of [Radical.Windows](https://github.com/RadicalFx/Radical.Windows) and mirrors its API, so moving an application from WPF to Avalonia is mostly a matter of changing `using` directives.

[Documentation](http://docs.radicalframework.com/) is composed of articles and guidance detailing how to get the most out of Radical.
